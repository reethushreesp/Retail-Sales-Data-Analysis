# Retail Sales Data Analysis – Microsoft Excel

## Project Overview
This project focuses on analysing retail sales data using Microsoft Excel. The goal is to clean the dataset, perform data analysis, identify sales trends, and present meaningful business insights through a dashboard.

## Tools & Technologies
- Microsoft Excel
- Excel Formulas (SUM, SUMIF, COUNTIF)
- Data Cleaning
- Data Analysis
- Charts and Dashboard

## Dataset
- 600 retail sales records
- Includes order details, customer information, product categories, sales channels, revenue, cost, and profit.

## Project Structure
The Excel workbook contains four sheets:

1. **Raw_Data** – Original dataset.
2. **Clean_Data** – Cleaned dataset with data quality checks.
3. **Analysis** – KPI calculations and summary tables.
4. **Dashboard** – Visual representation of key metrics and sales insights.

## Data Cleaning
- Corrected inconsistent text values.
- Identified missing values.
- Audited missing Customer IDs and other fields.
- Identified invalid discount and shipping-day values.
- Checked duplicate Order IDs.

## Key Performance Indicators (KPIs)
- Total Revenue: ₹11,363,033.03
- Total Profit: ₹1,221,970.82
- Total Orders: 600
- Total Quantity Sold: 1,134
- Profit Margin: 10.75%

## Key Business Insights
- East region generated the highest revenue.
- Electronics was the highest-revenue product category.
- Marketplace was the highest-revenue sales channel.
- Overall profit margin was 10.75%.

## Conclusion
This project helped me gain practical experience in Excel-based data cleaning, data analysis, KPI calculations, and dashboard creation. It demonstrates how raw sales data can be transformed into meaningful business insights.
